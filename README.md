# GearLLM

This codebase is a modified version designed to run GearDVFS on on-device SLM (Small Language Model) inference targets.

## Overview

This project integrates GearDVFS with llama.cpp to enable efficient power management and performance optimization for small language model inference on edge devices.

**Important:** Before using this repository, please first clone and build [llama.cpp_Customized](https://github.com/MaverickJune/llama.cpp_Customized) at the same directory level as where you will clone this repository.

## Features

- On-device SLM inference support
- Performance monitoring and profiling
- Dynamic voltage and frequency scaling (DVFS) integration
- Support for NVIDIA Jetson platforms
